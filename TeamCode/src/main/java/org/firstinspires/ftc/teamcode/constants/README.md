# Robot Constants File

## Purpose
* Used to set all "variable things" on the robot
  * This can include motor names, speeds for each robot action, or numbers used in calculations like Pi.

## Why?
* Helps programmers to be more organized
  * If someone changes a motor name or needs more or less speed, it is very easy to find and change one value in this file,
    instead of having to replace 7 separate values.
