# Subsystem Code

## Purpose
* Used to control individual "sections" of the robot
  * Physically, it is pretty easy to tell what different parts of the robot do (for example, the drivetrain, the intake, or the pollen pusher).
  * In programming, without subsystems, it can be difficult for many (even more advanced) programmers to tell how a program controls the robot.

## Why?
* Helps other coders to be able to reuse others' code more easily
* Provides the opportunity to learn fundamental object-oriented programming skills
