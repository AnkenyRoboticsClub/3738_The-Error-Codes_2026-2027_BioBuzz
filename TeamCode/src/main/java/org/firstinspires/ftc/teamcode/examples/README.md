# Example TeleOp Code

## Purpose
* Used as somewhat generic examples to provide an idea of what "good" Java code looks like
* These examples are set to "Disabled", so they will **NOT** show up in the OpMode list on the Driver Station.

## Why?
* Helps less experienced coders to be able to look at real-life program examples
* Gets team members thinking, giving inspiration

> "For the things we have to learn before we can do them, we learn by doing them." - Aristotle
